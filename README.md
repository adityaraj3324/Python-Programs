# Python-Programs

This repository contains multiple **Python projects and experiments**, including programs for **Hotel Management System**, **Digital Image Processing (DIP)**, and other utility-based projects. The repo also includes sample datasets, images, and audio files that support the implementation of these projects.

---

## Contents

* **Hotel Management System**
  A Python project (Jupyter Notebook) to manage hotel data including customer details, bookings, and record management. It uses datasets like `hotel_data.xlsx` for data handling and demonstrates practical application of Python in real-world scenarios.

* **DIP (Digital Image Processing)**
  Contains a Jupyter Notebook (`DIP.ipynb`) focusing on digital image processing concepts and applications. Supporting images (`BT.jpg`, `DD1.jpg`, etc.) are included for experiments.

* **Alarm Clock**
  A Python notebook (`Alarms.ipynb`) with an alarm feature, supported by an audio file (`alarm.wav`).

* **Supporting Media**

  * Image files (e.g., `BT1.jpg`, `DD2.jpg`) used for testing DIP programs.
  * Excel dataset (`hotel_data.xlsx`) used by the Hotel Management System.
  * Audio files used in the Alarm project.

---

## How to Use

1. Clone this repository:

   ```bash
   git clone https://github.com/adityaraj3324/Python-Programs.git
   ```
2. Open the Jupyter notebooks in your environment:

   ```bash
   jupyter notebook
   ```
3. Navigate to the desired `.ipynb` file and run the code cells.
